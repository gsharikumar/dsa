Vertical Width of a Binary Tree
Difficulty: Medium

Given a root of binary Tree. Find and return the vertical width of the tree.

Examples :

Input: root = [1, 2, 3, 4, 5, 6, 7, N, N, N, N, N, 8, N, 9]

Output: 6
Explanation: The width of a binary tree is the number of vertical paths in that tree.

The above tree contains 6 vertical lines.
Constraints:
0 ≤ number of nodes ≤ 104
