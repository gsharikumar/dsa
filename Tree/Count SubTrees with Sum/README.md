Count SubTrees with Sum
Difficulty: Medium
You are given a root of  binary tree and an integer x. Your task is to count the number of subtrees whose sum of all node values is equal to x. The sum of a subtree is the sum of all node values within it.

Examples:

Input: root = [5, -10, 3, 9, 8, -4, 7 ], x = 7

Output: 2
Explanation: Subtrees with sum 7 are [9, 8, -10] and [7].
Input: root = [1, 2, 3], x = 5

Output: 0
Explanation: No subtree has sum equal to 5.
Constraints:
1 ≤ number of nodes ≤ 105
-105 ≤ node value ≤ 105
